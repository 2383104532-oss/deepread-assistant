# DeepRead Assistant — Group-Meeting Paper Reading Studio

A custom **dsh-worktable** window that turns reading a paper, taking notes, and rehearsing a group-meeting talk into one flow. Pure client-side HTML + JavaScript; the summaries are generated by the LLM of your choice (GLM / DeepSeek / GPT, or any OpenAI-compatible endpoint).

## What it does

**① Deep Read** — load any paper PDF (by folder + filename, or upload a local PDF which is auto-saved into a project folder named after it). It then generates a "story-driven" structured summary:
> old belief (what we used to think / how far we got) → new pain point (what was still unsolved) → new contribution (what I found that makes it a non-issue), each with the original text quote and your analysis.

The summary is rendered as Markdown (readable, copyable). You can choose the model: **Zhipu GLM** (multimodal — sees figures/tables), **DeepSeek** (text), **GPT / OpenAI** (optionally multimodal), or any OpenAI-compatible endpoint by setting Base URL + API Key + model name.

**② Ask + Notes** — a two-step gate:
- *Part 1 · Clarify*: one question at a time, adaptive follow-ups driven by your answers, until the assistant understands your reading goal.
- *Part 2 · Lock target*: generate a "goal restatement + checklist", lock it, then generate a full reading note (paper profile / PSR / contribution breakdown / how experiments were run / key evidence / my thoughts / relation to my research / quality assessment).

**③ Rehearsal** — load the paper's PPT; the page auto-converts it (via the workspace terminal calling local PowerPoint/python-pptx) into a view + per-slide speaker notes, side-by-side, 16:9, zoomable, with prev/next + wheel navigation, and a timer.

## How it works

- Single file `deepread.html`, styled by the dsh-worktable native skin (`/api/worktable/template/dshell.css`).
- Uses workspace APIs: `/api/worktable/site`, `/api/worktable/file`, `/api/worktable/write`, `/api/worktable/mkdir`, `/api/worktable/term`.
- All LLM calls use the **OpenAI-compatible `/chat/completions`-style endpoint** (works with DeepSeek, Zhipu, OpenAI, local Ollama, etc.).
- API keys are entered in the page and stored **only in browser localStorage** — not in any file, not in this repo.
- `make-ppt-view.ps1` — converts a `.pptx` to `<PPT名>.pdf` (via PowerPoint COM) and extracts `<PPT名>.md` speaker notes (via python-pptx).
- `save-upload.ps1` — decodes an uploaded PDF (base64) into a real PDF inside a project folder.

## Setup

1. Put `deepread.html` and both `.ps1` scripts in the root of a DSH workspace project.
2. Add a mount manifest `widget-result.json` (an example is included):
   ```json
   {"window":"窗口1","path":"deepread.html","kind":"html"}
   ```
3. Open the window, pick a summary model, enter its API key (stored locally), and click "Save configuration".
4. Load a paper PDF (or upload one) to auto-generate the summary, then walk through ② Ask+Notes and ③ Rehearsal.

> `make-ppt-view.ps1` / `save-upload.ps1` require **Microsoft PowerPoint** and **python + python-pptx** installed locally. "Auto-save upload" and "PPT auto-convert" need the dsh-worktable terminal (`/api/worktable/term`) to be available.

## Privacy

- API keys only live in the browser's localStorage — they never leave your machine.
- Your papers, notes, summaries, and reading state are personal research data and are excluded from this repository by design (see `.gitignore`).
